# 黄金业务闭环

> 适用阶段：一期  
> 更新日期：2026-09-12  
> 来源：`docs/specs/00-project/正式项目计划.md`

```text
销售订单产生需求
  → 人工判断现货与生产需求并建立来源关联
  → 创建生产工单并关联销售订单行
  → 原料不足时人工创建并关联采购订单
  → 仓库到货外观验收，可在收货前全部或部分拒收
  → 实际接收数量进入质量隔离位并增加企业实物库存
  → 生产质检人员记录采购到货质检结果
  → 放行、退回供应方或报废决定
  → 仓库确认实际移位、退回或报废扣减
  → 合格物料上架，只改变库存位置
  → 生产工单提交、审核并下达
  → 生产领料确认，仓库库存减少
  → 派工和工序执行
  → 设备上报遥测，异常时生成告警
  → 报工和生产质量检验
  → 合格品完成成品入库
  → 销售直接拣货，在同一事务内自动预留并移位
  → 发货确认，扣减企业实物库存并释放对应预留
```

关键限制：一期只做人工供需关联，不自动计算需求、不自动生成工单或采购建议，也不实现自动排产。
