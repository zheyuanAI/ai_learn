# WMS AI 受控知识集

> 适用阶段：阶段 8  
> 更新日期：2026-09-12  
> 正式事实源：实际代码、`docs/specs/00-project/` 与各领域规格

本目录是提供给 Open WebUI Knowledge 的受控知识视图，帮助模型理解本项目的术语、角色、流程、状态和异常处理边界。

本目录不是新的业务事实源。业务规则发生变化时，必须先修改正式领域规格，再同步这里；实时订单、库存、任务、告警和操作历史必须调用 WMS 只读工具查询，不能用知识文档代替。

## 同步规则

- 只同步 `knowledge-manifest.yaml` 中 `enabled: true` 的文件；
- 禁止同步历史计划、废止规则、源代码全集、日志、数据库备份、密钥和构建产物；
- Open WebUI 不得直连 WMS PostgreSQL；
- 文档中标记为“目标”的工具或能力不能表述为已经实现；
- 知识回答应引用知识文档，实时业务回答应同时给出 WMS 工具来源和数据时间范围。

## 更新流程

1. 核对实际代码与正式领域规格；
2. 修改对应知识文档的内容、来源和更新日期；
3. 更新 `knowledge-manifest.yaml` 的 `revision`；
4. 将清单内文档同步到 Open WebUI；
5. 使用固定验收问题检查检索结果，确认没有引用历史或冲突规则。
