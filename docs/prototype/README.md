# Prototype 高保真原型说明

## 定位

- 本目录展示一期全业务模块目标设计高保真静态原型，不代表对应业务后端接口或功能已经实现；
- 所有页面围绕一条黄金业务闭环表达业务意图、执行过程与不可篡改事实记录；
- 页面中的字段、状态、动作和接口占位以正式 `docs/specs/00-project/原型与交互说明.md`、对应领域的 `概述.md`、`领域模型.md`、`接口契约.md`、`验收标准.md`、`全模块业务规则总览.md` 与实际代码为准；
- 任意原型页右上角的“业务架构”链接只跳转 `docs/业务架构/index.html` 主入口；不与具体模块架构页绑定，也不共享浏览器状态；
- 全模块高保真控制台已全面遵循统一暗色工业风格规范，支持多角色切换、多场景切换、动作模拟、参数校验、影响说明与审计时间线。

## 一期黄金业务闭环

```text
销售订单 100 件需求 (SO-20260826-018)
-> 人工关联来源销售行与生产工单 (WO-20260826-018, 计划 80 台)
-> 人工创建采购订单并关联来源工单 (PO-20260826-001, 80 件)
-> 仓库到货外观验收；收货前可全部或部分拒收 (拒收 5 件破损，不入库并继续待收)
-> 实际接收数量 (75 件) 全部进入 QualityHold（质量隔离位）
-> 生产质检人员完成采购到货质检 (70 件合格，5 件不合格)
-> 生产质检决定放行/报废，采购人员决定退回供应方
-> 仓库人员确认处置实物执行 (放行 70 件移至 RS-01 收货暂存位，报废 5 件扣减实物记流水)
-> 仓库人员确认上架至 Storage（存储位 ST-A-01）
-> 生产领料确认 (MI-20260826-001, 领用 70 套扣减原料库存)
-> 派工与 OperationExecution (OE-20260826-033 在 DEV-C12 执行性能检测标定)
-> MQTT 消息去重 (QoS 1)、遥测追加、设备状态快照与超温告警 (ALM-20260826-003)
-> 工序报工 (合格 58，不良 2)、成品质检与成品入库 (FGR-20260826-001, 入库至 FG-A-01)
-> 销售直接拣货；系统内部自动预留并移动到发货暂存位 (SHP-01)
-> 发货确认扣减企业总实物库存并释放对应预留
-> 二维地图、综合看板、跨域追溯与 AI 受控只读查询
```

一期只提供人工供需关联，不包含自动 MRP、自动缺口计算、自动工单生成或自动采购建议。

## 关键库存语义与业务守恒

- `available_qty = on_hand_qty - reserved_qty`，且 `available_qty >= 0`；
- 收货前拒收数量不增加企业总实物库存、不计入采购累计已收货并继续作为待收数量；
- 收货确认只按 `received_qty（实际接收数量）` 增加企业总实物库存，并全部进入 `QualityHold（质量隔离位）`；采购到货质检记录合格/不合格数量但不改变库存，合格放行执行后移入 `ReceivingStaging（收货暂存位）`；
- 上架确认只移动位置，不重复增加企业总库存；
- 销售直接拣货在同一事务内自动增加本次所需 `reserved_qty`，再将来源库位的实物与有效预留分配同步移动到 `ShippingStaging（发货暂存位）`，不扣减企业总库存；
- 退回拣货将实物与有效预留分配同步退回来源库位，不做业务释放；
- 发货确认才扣减企业总实物库存和对应预留分配，并释放对应预留；
- 销售订单生命周期固定为 `Draft / Submitted / Approved / Completed`，履约进度由订单行数量动态派生；
- 生产领料减少仓库库存，生产退料增加退回库位库存。

## 高保真页面清单

- **流程评审入口**：`pages/workflow-wireframe.html`，用于切换六类角色并核对黄金闭环的权限、状态、接口和页面跳转
- **认证与总览**：
  - `index.html`：原型总览与黄金业务闭环导航
  - `pages/login.html`：统一身份认证与单会话顶替（后登踢前）高保真控制台
  - `pages/dashboard.html`：跨域 7 大事实综合只读看板（30s 自动刷新）
- **供需与仓储**：
  - `pages/master-data.html`：商品物料、6 类标准库位、实时库存余额、调拨与差异盘点流水控制台
  - `pages/purchase-inbound.html`：采购外观验收、质量隔离位看板、到货质检、处置执行与上架控制台
  - `pages/sales-outbound.html`：销售直接拣货（内部自动预留）、移位与发货扣减履约控制台
- **制造执行 (MES)**：
  - `pages/work-order.html`：工单下达、BOM/工艺路线锁定、领退料、OperationExecution 状态机、报工与成品入库控制台
- **设备事实 (IoT)**：
  - `pages/device-alarm.html`：MQTT QoS 1 消息去重、实时遥测曲线、单指标阈值告警生命周期与工序上下文控制台
- **GIS 与 AI 空间分析**：
  - `pages/site-map.html`：厂区二维平面地图、百分比坐标、4 级状态优先级与穿透直达控制台
  - `pages/ai-assistant.html`：Grok-4.6 / PokeAPI 受控只读助手、全链追溯卡片生成与写操作拦截控制台
  - `pages/tool-audit.html`：AI 受控工具调用全量审计日志与详情抽屉控制台
- **二期设计资产（保留不验收）**：
  - `pages/digital-twin.html`：三维展示与数字孪生预留资产
  - `pages/knowledge-base.html`：企业知识库与 RAG 预留资产

## 页面审查与连贯演示顺序

1. **登录与角色加载**：打开 `pages/login.html`，快速切换角色体验菜单权限与单会话规则；
2. **总览全局事实**：打开 `pages/dashboard.html`，核对 7 大事实域指标、时间范围切换与 30s 自动刷新；
3. **销售需求发起**：打开 `pages/sales-outbound.html`，查看 `SO-20260826-018`（100 件需求，L10 行）；
4. **制造工单拆解**：打开 `pages/work-order.html`，查看 `WO-20260826-018` 关联 L10，体验工单下达锁定 BOM、领料扣减、Op 30 执行与报工；
5. **采购到货与质检**：打开 `pages/purchase-inbound.html`，查看 `PO-20260826-001` 关联工单，体验外观拒收 5 件（不入库/待收）、实收 75 件进 QualityHold、质检 70 合格 / 5 不合格、放行执行移至 RS-01 及上架；
6. **库存余额与主数据**：打开 `pages/master-data.html`，核对 6 类标准库位库存分布，演示调拨与盘点调整；
7. **设备遥测与告警**：打开 `pages/device-alarm.html`，体验 `DEV-C12` 消息去重、超温 78.5℃ 告警触发/确认/恢复，查看关联的 OE-033；
8. **厂区空间感知**：打开 `pages/site-map.html`，查看 2D 地图点位状态高亮，点击点位抽屉直达业务控制台；
9. **销售直接拣货与发货**：回到 `pages/sales-outbound.html`，执行直接拣货（自动预留 40 件移至 SHP-01）与发货 20 件（扣减总库存）；
10. **AI 智能追溯与审计**：打开 `pages/ai-assistant.html`，输入提示词追溯 SO-018 全链事实，体验写操作防御拦截，最后在 `pages/tool-audit.html` 审查工具调用日志。
