Spec Driven / Prototype First

制造与仓储协同平台原型总览

这套原型用于评审一期目标设计：以一条黄金业务闭环连接销售需求、采购、库存、制造与设备事实，再由地图、看板、追溯和 AI 只读呈现。页面不代表业务功能已经实现；三维与知识库仅保留为二期设计资产。

一期业务主线

  • 从销售订单 100 件需求出发，人工关联生产工单与采购来源
  • 外观验收、到货质检、上架、领退料、工序执行、成品入库、直接拣货与发货形成一条链
  • 库存流水、OperationExecution、遥测和告警作为可追溯业务事实

事实边界

  • 预留只增加 `reserved_qty`，不扣减 `on_hand_qty`
  • 实际接收先进入质量隔离位；质检不改库存，放行、上架与直接拣货只移动位置，发货才扣减企业总库存
  • 设备遥测、设备状态与设备告警分别保存，再补充工序执行上下文

展示边界

  • 二维地图与看板只读展示同一套业务事实
  • AI 只通过受控只读工具查询，并展示来源、时间范围与调用摘要
  • 三维数字孪生和知识库明确留作二期，不进入一期验收

一期黄金业务闭环

01
需求与人工来源
销售订单行 -> 生产工单 -> 采购明细关联来源工单
02
采购与仓储
外观验收 -> 全部接收进入质量隔离位 -> 到货质检 -> 合格放行 -> 上架移动
03
制造执行
生产领料 -> 派工 -> OperationExecution -> 报工 -> 质检 -> 成品入库
04
设备事实
MQTT 消息去重 -> 遥测 -> 状态 -> 告警 -> 工序执行上下文
05
销售交付
直接拣货（内部自动预留并移位）-> 发货扣减并释放对应预留
06
只读追溯
二维地图 / 看板 / 追溯 / AI -> 同一事实来源与审计
