02

统一授权规则

所有业务页面共同遵守

  1. Gateway 校验 JWT 签名、有效期和当前 jti。
  2. Auth 根据账号角色判断功能权限，Redis 仅作为权限高速缓存。
  3. 业务服务再次校验当前租户、对象状态和具体业务规则。
  4. 同一账号后登录替换前登录；旧会话再次请求返回 401。
  5. 系统记录账号与会话，不承诺识别共享账号背后的自然人。
