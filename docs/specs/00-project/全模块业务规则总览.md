# 全模块业务规则总览

> 状态：一期业务设计已完成逐模块确认  
> 确认日期：2026-08-28  
> 说明：本文汇总跨模块关系与边界。具体状态、数量和异常处理以各模块业务规则文件为准；目标接口不表示当前代码已经实现。

## 1. 模块范围

一期业务由以下七组能力组成：

1. 库存与仓储：维护实物库存、预留、移动、流水、调拨和盘点事实。
2. 销售：管理销售订单、分批直接拣货（内部自动预留）、分批发货和人工完成。
3. 采购：管理采购订单、分批到货外观验收、收货前拒收、实际接收、到货质检、质量处理、上架和人工完成。
4. 生产与质检：管理生产工单、审核、派工、工序执行、领退料、报工、检验和成品入库。
5. IoT（物联网设备接入）：管理设备、凭证、遥测、状态和告警。
6. GIS（二维位置展示）与综合看板：只读展示地图点位和跨模块摘要。
7. AI 助手：通过受控只读工具查询和解释业务事实。

## 2. 黄金业务闭环

```text
销售订单
  -> 人工关联生产工单
  -> 生产工单人工关联一条来源销售订单明细
  -> 同一销售订单明细允许拆分为多个生产工单
  -> 采购明细人工关联生产来源
  -> 仓库到货外观验收（可全部或部分拒收），实际接收数量全部进入质量隔离位
  -> 生产质检人员检验并决定放行/报废，或采购人员决定退回供应方
  -> 仓库确认质量处置实物执行与上架
  -> 工单审核与下达
  -> 生产质检人员创建领料单，仓库确认发料
  -> 派工、工序执行、报工与质检
  -> 生产质检人员创建成品入库单，仓库确认实物入库
  -> 销售直接拣货（内部自动预留）与发货
  -> IoT 告警、地图、看板、追溯和 AI 只读查询
```

一期不实现 MRP（物料需求计划：自动计算生产和采购缺口）、自动工单、自动采购建议、APS（高级排产：根据产能自动安排生产）或返工流程。

## 3. 跨模块事实边界

| 模块 | 自己保存的事实 | 不允许承担的职责 |
| --- | --- | --- |
| 库存 | 库存余额、预留分配、库存流水、位置移动、盘点调整 | 不替订单或生产决定业务状态 |
| 销售 | 客户需求、订单状态、累计预留/拣货/发货数量 | 不直接修改库存余额 |
| 采购 | 采购意图、到货拒收、累计实际收货、质量处置决定与上架进度 | 不绕过库存服务记账 |
| 生产质检 | 工单、派工、执行、报工、质检和成品入库来源 | 不直接修改库存或复制 IoT 遥测 |
| IoT | 设备、凭证、原始遥测、当前状态和告警 | 不直接修改生产工单 |
| GIS 看板 | 二维点位配置和只读查询结果 | 不形成第二套业务事实，不执行业务操作 |
| AI 助手 | 会话和工具审计 | 不直连数据库，不修改业务数据 |

## 4. 统一数量原则

- 库存满足 `available_qty = on_hand_qty - reserved_qty >= 0`。
- 预留只减少可用量，不减少实物库存。
- 到货验收满足 `arrived_qty（到货数量） = rejected_qty（收货前拒收数量） + received_qty（实际接收数量）`；质检满足 `inspected_qty（检验数量） = qualified_qty（质检合格数量） + unqualified_qty（质检不合格数量）`。
- 收货前拒收不进入库存、不计入采购累计已收货并继续作为待收数量；收货确认只按实际接收数量增加实物库存，且全部进入质量隔离位；质检不改变库存，放行和上架只移动位置。
- 直接拣货在同一事务内自动预留并移动到发货暂存位，发货确认才减少企业总实物库存。
- 生产领料减少原料库存，生产退料增加退回库位库存，合格成品入库增加成品库存。
- 任何累计数量不得超过对应单据允许上限；重复命令不得重复形成业务事实。

## 5. 正常完成与人工完成

- 销售、采购和生产工单均区分正常完成与人工完成。
- 人工完成只终止尚未发生的剩余履约，不补造收货、上架、报工、质检、入库、拣货或发货事实。
- 人工完成必须记录原因、账号、会话标识和时间。
- 已经发生的业务和库存历史永久保留。

## 6. 权限与审计

- 所有查询和写入均使用服务端认证上下文确定租户和用户，客户端不得指定可信租户。
- 页面隐藏按钮不能代替后端授权；后端继续校验角色、对象状态、数量、数据范围和租户。
- 影响业务事实的命令必须幂等（同一业务请求重复提交只生效一次）。
- 跨模块关联使用业务标识和应用服务，不跨模块直接修改数据表。

关键节点职责固定如下：

| 业务节点 | 决定/创建角色 | 实物执行/确认角色 |
| --- | --- | --- |
| 关联采购来源 | 采购人员 | 不适用 |
| 到货验收、收货前拒收与实际接收 | 仓库人员 | 仓库人员 |
| 采购到货质量检验 | 生产质检人员 | 不适用 |
| 质量放行/报废 | 生产质检人员 | 仓库人员 |
| 退回供应方 | 采购人员 | 仓库人员 |
| 生产领料 | 生产质检人员创建领料单 | 仓库人员确认发料 |
| 工单审核、派工与工序执行 | 生产质检人员 | 生产质检人员 |
| 成品入库 | 生产质检人员创建入库单 | 仓库人员确认实物入库 |
