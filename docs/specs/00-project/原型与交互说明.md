# 原型范围

一期原型服务于一个月内交付的黄金业务闭环。二维地图、综合看板和 AI 助手仅提供轻量只读展示与查询；数字孪生仿真和知识库训练属于二期，不进入一期实现与验收。

## 一期必须实现的原型页面
- 登录页
- 首页综合看板
- 商品、仓库、收货暂存位、发货暂存位、普通库位管理
- 采购单、入库单、上架任务页
- 销售单、拣货任务、出库单页
- 工单列表、工单详情、领退料、派工、工序执行、报工与质检页
- 设备列表、设备详情、告警页
- 厂区二维地图页
- AI 助手聊天页、追溯查询页、调用审计页

## 二期原型资产

- 三维展示页：保留现有页面用于二期讨论，不进入一期实现与验收
- 知识库管理页：保留现有页面用于二期知识库训练和 RAG 设计，不进入一期实现与验收

## 原型阶段交付要求
- 使用假数据即可
- 先固定字段、列表列、详情页结构、状态标签、主要操作按钮
- 每个页面标出需要的接口、权限点、状态流转
- 产出页面导航图和主流程跳转图

## 原型验收
- 能串起一期黄金业务闭环，并分别演示采购收货/上架、生产领退料与执行、库存预留/拣货/发货、MQTT 告警、跨域追溯、二维地图和 AI 只读查询
- 每个关键单据至少包含列表、详情、创建/提交/确认等核心动作
- 二维地图、看板、AI 只读工具页面有明确的数据占位与交互说明
