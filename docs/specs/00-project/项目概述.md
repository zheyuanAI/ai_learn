# 项目总览

## 项目目标
一个月内交付一个可演示的制造与仓储协同执行平台一期黄金业务闭环。以“销售需求—人工供需关联—采购入库—生产领料与工序执行—成品入库—销售发货”为黄金业务闭环，覆盖库存内核、制造执行、IoT 设备事实、跨域追溯，以及轻量只读的二维地图、看板和 AI 查询。

## 范围
- ERP/WMS：采购、到货外观验收、质量隔离、采购到货质检、收货暂存、上架、库存余额/预留/流水、销售直接拣货、发货、调拨和盘点
- MES：BOM、简化工艺路线、来源销售行、工单、派工、领退料、工序执行、报工、质检和成品入库
- IoT：设备模型与凭证、MQTT 模拟接入、遥测、状态、告警、恢复和消息去重
- 追溯/GIS/看板：跨域追溯、异常查询、二维厂区地图、点位和事实摘要
- AI 助手：受权限约束的业务只读工具、追溯查询、告警解释、简单日报和调用审计

## 二期候选范围

- Ditto 数字孪生仿真、数字孪生平台集成和 Cesium 三维表达
- OFBiz 能力整合，以及收付款、核销、账龄等完整财务能力
- Modbus TCP、OPC UA 与真实工业设备适配
- RAG 知识库训练、文档解析、MinIO、pgvector 和向量检索
- MES 产能日历、自动排程、返工单和复杂质检
- 通用 Outbox + RabbitMQ 可靠事件体系
- 序列号、保质期及其与批次组合的复杂库存模型

## 非目标
- 不追求生产级高可用部署
- 不实现 APS、自动排程和产能优化
- 不实现自动 MRP、自动工单或采购建议
- 不追求真实 PLC 厂商设备深度适配
- 不做会修改业务数据的 AI Agent

## 成功标准
- 一期黄金业务闭环可完整跑通，并可从销售订单、工单、库存流水或设备告警追溯关键上下游
- 多租户隔离、权限控制、幂等和关键状态流转有自动化测试覆盖
- 本地文档可从零启动 PostgreSQL、Redis 和 Mosquitto，Gateway 使用 20001，Auth/Core/IoT 使用 10002—10004
- 每个子域都有 spec、原型、API 契约、验收清单
