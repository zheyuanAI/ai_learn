# 库存业务规则

> 状态：一期目标设计已确认  
> 确认日期：2026-08-27

## 1. 事实模型

- `InventoryBalance`（库存余额）：按租户、产品、仓库、库位和可选批次保存当前查询快照。
- `InventoryReservation`（库存预留）：表达销售等业务对现有库存的占用承诺。
- `InventoryTransaction`（库存流水）：记录每次库存数量、位置或预留变化的不可随意修改事实。
- 库存余额可由有效库存流水和预留记录核对，但不得由普通用户直接覆盖。

统一公式：

```text
available_qty = on_hand_qty - reserved_qty
available_qty >= 0
```

其中 `on_hand_qty` 是实物数量，`reserved_qty` 是已占用数量，`available_qty` 是仍可分配数量。

## 2. 库位类型

| 库位 | 释义 | 允许的主要动作 |
| --- | --- | --- |
| `ReceivingStaging`（收货暂存位） | 采购到货质检合格并已执行放行、尚未完成上架的货物位置 | 质量放行移入、上架移出 |
| `Storage`（存储位） | 正常长期存放货物的位置 | 上架、调拨、盘点 |
| `Picking`（拣货位） | 面向出库拣选的货物位置 | 补货、拣货、退回 |
| `ShippingStaging`（发货暂存位） | 已拣货、尚未确认发货的位置 | 拣货移入、退回、发货扣减 |
| `QualityHold`（质量隔离位） | 实物已经存在但暂时禁止正常使用的位置 | 质量放行、退回或报废处置 |
| `Adjustment`（调整位） | 盘点或异常调整使用的受控位置 | 仅授权调整 |

## 3. 库存关键时点

| 动作 | 企业总实物库存 | 可用量 | 位置 |
| --- | --- | --- | --- |
| 采购收货确认 | 按实际接收数量增加 | 不增加正常可用量 | 实际接收数量全部进入质量隔离位 |
| 采购到货质检 | 不变 | 不变 | 只记录合格/不合格数量，仍在质量隔离位 |
| 质量放行执行 | 不变 | 增加 | 合格数量从质量隔离位移至收货暂存位 |
| 上架确认 | 不变 | 不重复增加 | 暂存位移至目标存储位 |
| 销售直接拣货 | 不变 | 同一事务内自动预留本次数量后保持业务占用 | 来源库位移至发货暂存位 |
| 退回拣货 | 不变 | 企业合计不变 | 发货暂存位移回合法库位 |
| 发货确认 | 减少 | 释放对应预留 | 从企业库存移出 |
| 生产领料 | 减少 | 同步变化 | 从仓库交付生产 |
| 生产退料 | 增加 | 同步变化 | 退回指定仓库库位 |
| 成品入库 | 增加 | 同步变化 | 进入指定成品库位 |
| 调拨 | 不变 | 按位置重新计算 | 来源库位移至目标库位 |

## 4. 调拨规则

- 调拨必须指定产品、来源仓库/库位、目标仓库/库位和数量。
- 来源与目标不得相同，来源可用库存必须充足。
- 调拨确认在同一事务中减少来源、增加目标并形成对应流水，企业总实物库存不变。
- 调拨失败不得只完成单边库存变化。

## 5. 盘点规则

页面状态统一显示：

```text
未盘点 -> 盘点中 -> 已确认并调整
```

- 未盘点时生成盘点范围并冻结本次系统数量快照。
- 盘点中录入实盘数量和差异原因；不得直接修改库存余额。
- “确认并调整”后，根据 `实盘数量 - 系统数量` 生成库存调整流水，再更新余额。
- 无差异时仍保存盘点确认事实，但不生成数量变化流水。
- 已确认并调整的盘点单不得重复确认；同一幂等键重复提交返回首次结果。

## 6. 异常与调整

- 报废（确认实物不再可用并从库存扣除）必须填写原因、数量、操作人和时间，并生成库存减少流水。
- 质量隔离货物不得参与正常销售预留或生产领料。
- 库存不足、版本冲突、重复业务载荷冲突或跨租户引用时，整次命令失败，不产生部分库存事实。
- 任何调整都必须引用来源业务；不存在来源事实时使用受控异常调整来源，并要求额外权限与原因。

## 7. 一期边界

- 支持可选批次编号，但不实现序列号、保质期和复杂批次组合规则。
- 不实现 WIP（在制品库存：工序之间尚未完工的库存）或线边仓。
- 不实现自动补货、自动分配策略或自动波次拣货算法；直接拣货命令按用户指定的来源库位自动补足本次数量所需预留，不属于自动分配策略。
