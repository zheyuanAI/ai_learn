# ERP/WMS 概览

## 目标
建立采购、销售和制造共同使用的库存事实内核，跑通采购外观验收、质量隔离、到货质检、放行上架与销售直接拣货/发货，并为生产领料、退料和成品入库提供统一库存服务。

## 关键场景
- 销售订单行 -> 人工关联生产工单 -> 人工关联采购来源
- 采购订单 -> 仓库外观验收（可全部或部分拒收）-> 实际接收数量全部进入质量隔离位 -> 采购到货质检 -> 合格放行到收货暂存位 -> 上架只移动位置
- 销售订单 -> 直接拣货（同一事务内自动预留并移动到发货暂存位）-> 发货扣减实物库存
- 销售订单允许分批直接拣货和分批发货；不再履约的剩余数量可由销售人员人工完成
- 生产领料/退料/成品入库 -> 统一库存流水
- 调拨、盘点 -> 余额调整与来源追溯

## 核心约束
- `available_qty = on_hand_qty - reserved_qty`，任何时候不得小于零
- 余额用于查询，预留表达业务占用，流水记录不可随意修改的库存事实
- 收货前拒收数量不进入库存；实际接收数量全部进入质量隔离位并增加一次总库存；质检不改变库存，放行和上架只移动位置；直接拣货不扣减总库存，发货才扣减
- 关键命令同时使用数据库事务、幂等键与版本/锁控制，避免重复记账和并发超卖
- 人工完成只终止单据剩余履约，不得伪造收货、拣货、发货或库存流水

## 一期边界
- 供需关系由业务人员人工建立，不实现 MRP、自动缺口计算或采购建议
- 应收/应付草稿若保留，仅作追溯附属结果，不属于黄金闭环核心验收
- 序列号、保质期及复杂批次组合、收付款、核销、账龄和完整财务进入二期候选
