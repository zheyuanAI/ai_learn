# ERP/WMS 验收清单

## 核心验收
- 收货确认后，收货暂存位 `on_hand_qty` 增加且生成来源明确的库存流水
- 上架确认后，总 `on_hand_qty` 不变，仅暂存位减少、目标库位增加
- 销售预留后，`reserved_qty` 增加、`available_qty` 减少、`on_hand_qty` 不变
- 拣货确认后，库存移动到发货暂存位，总 `on_hand_qty` 不变
- 发货确认后，发货暂存位实物库存减少并释放对应预留
- 生产领料、退料和成品入库通过同一库存应用服务产生可追溯流水
- 调拨保持企业总库存不变；盘点差异以调整流水入账

## 页面验收
- 商品列表展示：`sku`、`name`、`spec`、`uom`、`batch_managed`、`status`
- 库存页分别展示实物、预留、可用、库位、版本和最近流水
- 采购页明确区分收货与上架的库存影响，并展示可选来源工单
- 销售页展示预留前后摘要、来源/发货暂存位、拣货和发货结果
- 所有业务单据详情展示当前状态、来源关系和后端允许的操作

## 黄金链路相关场景

### 场景 1：采购收货与上架
- 前置：采购单已审批，收货暂存位和目标库位启用
- 操作：确认收货 -> 确认上架
- 结果：收货时总库存增加一次；上架仅改变位置；两步流水均可回到采购明细

### 场景 2：销售预留、拣货与发货
- 前置：库存充足，销售单已审批
- 操作：预留 -> 拣货 -> 发货
- 结果：预留只影响可用量；拣货只影响位置；发货才扣减实物并释放预留

### 场景 3：人工供需关联
- 操作：生产工单选择来源销售行，采购明细选择来源生产工单
- 结果：可查询关联，但系统不自动计算缺口、生成工单或采购建议

## 自动化验收
- 重复收货、上架、预留、拣货、发货不重复产生库存事实
- 两个并发预留请求不能使 `available_qty < 0`
- 上架不重复增加总库存，拣货不提前扣减总库存
- 发货数量不能超过有效预留和发货暂存位数量
- 库存余额可由有效流水和预留核对
- 跨租户库存、预留、单据和来源关联不可见

## 二期不验收
- 自动 MRP、收付款、核销、账龄、完整财务、序列号、保质期和复杂批次组合
