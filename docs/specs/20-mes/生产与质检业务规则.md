# 生产与质检业务规则

> 状态：一期目标设计已确认  
> 确认日期：2026-08-27

## 1. 业务对象与边界

- `WorkOrder`（生产工单）：表达生产什么、生产多少以及计划时间的生产意图。
- `DispatchOrder`（派工单）：把某道工序、数量、人员和可选设备安排给执行方，不代表现场已经开始。
- `OperationExecution`（工序执行）：记录某道工序实际开始、暂停、恢复和完成的事实。
- `WorkReport`（报工）：记录工序执行后申报的合格数量和不良数量。
- `QualityInspection`（质量检验）：确认报工数量是否允许成为合格成品。
- `FinishedGoodsReceipt`（成品入库）：将检验合格且尚未入库的数量增加到成品库存。

生产和质检共同完成业务闭环，但库存增减必须调用库存应用服务；制造模块不得直接修改库存余额。

## 2. 销售来源与计划数量

- 一个生产工单最多人工关联一条销售订单明细，也允许不关联销售来源。
- 同一条销售订单明细允许拆分为多个生产工单，用于分批或补充生产。
- 选择销售订单明细后，页面默认带出该明细尚未被其他有效工单承接的数量，并同时展示订单数量和已关联工单数量。
- 计划数量允许人工修改；修改不会改写销售订单数量，也不触发自动排产或采购。
- 来源关联只用于追溯和进度汇总，不构成库存预留，也不保证销售需求一定由该工单独占满足。

## 3. BOM 与工艺路线

- 工单必须选择有效 `BOM`（物料清单：生产产品所需原料及用量）和 `Routing`（工艺路线：产品依次经过的工序）。
- 工单审核通过并下达时锁定 BOM 与工艺路线版本。
- 已下达工单不得随意替换版本；确需变化时应人工终止原工单并创建新工单，不覆盖历史执行事实。

## 4. 工单状态与审核

```text
未提交 -> 待审核 -> 已下达 -> 生产中 -> 已完成
             |
             -> 审核拒绝 -> 修改并重新提交 -> 待审核
```

- 只有“未提交”和“审核拒绝”允许修改产品、计划数量、BOM、工艺路线、来源销售明细和计划时间。
- 审核拒绝必须填写原因；“审核拒绝”属于尚未下达阶段，但保留独立显示状态。
- 审核通过后进入“已下达”，之后才允许下达派工和领料。
- 第一次有效工序开始后进入“生产中”。
- 已完成继续区分“已完成（正常）”和“已完成（人工）”。

## 5. 派工与工序执行

- 派工和工序执行分开保存；派工生效不等于已经开工。
- 同一道工序可以分批派给不同人员，累计派工数量不得超过工单允许数量。
- 必需的上一道工序完成后才能开始下一道工序；一期不跟踪工序间 WIP（在制品库存）。
- 工序执行状态为：未开始 -> 进行中 -> 已暂停 -> 进行中 -> 已完成。
- 暂停必须填写原因；恢复沿用同一次工序执行记录，不创建新的工单或派工单。
- 每次开始、暂停、恢复和完成均记录实际操作人和时间。

## 6. 设备关联

- 设备为工序执行的可选项；没有设备也允许人工工序正常执行。
- 设备主数据长期关联工作中心、生产区域和地图点位。
- 某次生产使用哪台设备由工序执行记录保存，不在设备主数据上保存“当前工单”。
- IoT（物联网设备模块）保存设备遥测、状态和告警；MES（制造执行模块）只保存可选设备标识，不复制第二套设备事实。

## 7. 生产领料与退料

- 工单已下达后才允许生产领料；确认后通过库存应用服务减少原料库存。
- 库存不足时领料整单失败，不允许部分成功，也不允许产生负可用库存。
- 领料产品必须属于工单锁定的 BOM；超过预计用量时必须填写原因并由具有超额领料权限的人员确认。
- 生产退料数量不得超过该工单累计领料减累计已退数量；确认后增加指定退回库位库存。
- 一期不建立线边仓或在制品库存，因此领料后材料消耗只通过工单、领退料和报工追溯。

## 8. 报工、质检与不合格处理

- 工序完成后允许分批报工；报工数量等于申报合格数加不良数。
- 同一工序累计报工数量不得超过派工数量，也不得超过工单允许上限。
- 报工中的“申报合格”是生产人员申报结果，最终可入库数量仍由质量检验决定。
- 一期质检支持按报工批次记录检验数量、合格数量、不合格数量和结果。
- 不合格品进入质量待处理，可选择报废或暂时隔离；必须记录数量、原因、人员和时间。
- 报废不增加成品库存；因其从未成为成品库存，不生成成品库存扣减流水，但保留质量处置事实。
- 一期不建立返工单、返工状态机或重复质检流程。

## 9. 成品入库与完成

- 合格成品允许分批入库。
- 本次入库数量不得超过累计检验合格数量减累计已入库数量。
- 入库确认通过库存应用服务增加成品库存，并保存可追溯的库存流水关联。
- 正常完成要求必需工序已完成、数量全部已有报工和质量结果、不合格数量已有处置且合格数量已完成入库。
- 人工完成用于终止剩余生产，必须填写原因；不得补造领料、执行、报工、质检、入库或库存流水。
- 人工完成不覆盖已发生事实，未使用原料仍通过正常生产退料处理。

## 10. 幂等与异常

- 工单审核、派工下达、工序状态、领退料、报工、质检、入库和人工完成命令都必须幂等。
- 累计数量超限、非法状态迁移、跨租户关联、库存不足或同一幂等键载荷冲突时，整次命令失败。
- 生产、质量和库存事实使用来源业务标识关联，不跨模块直接修改数据表。

## 11. 一期边界

- 不实现 MRP、APS、产能日历、自动排产、线边仓、在制品库存和返工流程。
- 不实现复杂物料替代、联副产品、序列号和复杂批次追溯。
