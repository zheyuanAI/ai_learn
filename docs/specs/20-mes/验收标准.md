# MES 验收清单

## 验收前提

- 本清单验收的是一期目标能力；当前 MES 业务 Controller 尚未实现，不能把原型占位或本规格视为已实现结果。
- 接口实现后，场景中的失败分支必须返回 `接口契约.md` 定义的对应业务错误码。
- 所有场景必须在同一租户内建立合法关联，并额外执行跨租户拒绝用例。

## 核心验收

- `WorkOrder` 能表达生产意图，并可人工关联来源销售订单行；该关联不会自动计算工单数量或生成采购需求。
- `DispatchOrder` 只表达安排，不能被当作实际开工事实。
- `OperationExecution` 能记录一次实际开始、暂停、恢复和完成，且非法状态迁移被拒绝。
- `MaterialIssue`、`MaterialReturn` 确认后分别减少、增加仓库库存，并能追溯到库存事实。
- `WorkReport`、`QualityInspection`、`FinishedGoodsReceipt` 能按数量约束完成报工、质检和合格成品入库。
- 一期不存在 WIP 库存、线边仓、APS、自动排产和返工流程入口。

## 页面验收

- 工单列表至少展示：工单号、产品、来源销售订单行、计划数量、计划完工时间、状态、已报工、合格数、不良数、已入库数。
- 工单详情展示：BOM、工艺路线、来源销售订单行、领退料、派工、工序执行、报工、质检和成品入库追溯。
- 派工与工序执行必须分区展示，用户能区分“已安排”和“实际执行中”。
- 工序执行页展示：执行编号、工序、人员、可选设备、开始、暂停、恢复、完成时间和当前状态。
- 报工页显式区分：合格数量、不良数量和合计报工数量。
- 领退料与成品入库页展示库存确认结果及可追溯的库存业务标识。

## 场景验收

### 场景 1：人工关联来源并下达工单

- 前置：同租户的销售订单行、BOM 与 Routing 有效。
- 操作：创建 WorkOrder，人工选择 `source_sales_order_line_id`，再下达工单。
- 结果：工单保存来源关联并进入 `Released`；系统不自动改写 `planned_qty`，也不生成 MRP 或采购建议。
- 失败：关联不存在或跨租户销售订单行时返回 `MES_WO_004` 或 `MES_TENANT_001`；重复下达或在不满足条件时完成工单返回 `MES_WO_001`。

### 场景 2：派工与工序实际执行分离

- 前置：WorkOrder 已下达。
- 操作：创建并下达 DispatchOrder，创建 OperationExecution，依次开始、暂停、恢复、完成。
- 结果：派工保留安排信息；工序执行依次经过 `NotStarted -> Running -> Paused -> Running -> Completed` 并记录实际时间。
- 失败：未下达工单即开始执行返回 `MES_WO_002`；重复暂停、未暂停即恢复或完成后再次操作返回 `MES_EXE_001`。

### 场景 3：生产领料与退料连接库存

- 前置：原料库位库存充足，WorkOrder 已下达。
- 操作：创建并确认 MaterialIssue，再创建并确认部分 MaterialReturn。
- 结果：领料使仓库库存减少，退料使退回库位库存增加；两次变化均存在库存流水关联，MES 未建立 WIP 或线边仓余额。
- 失败：库存不足时领料整体失败并返回 `MES_MAT_001`；退料数量不合法时返回 `MES_MAT_002`。
- 幂等：使用相同 `Idempotency-Key` 重复确认时，库存只变化一次并返回第一次结果。

### 场景 4：报工、质检与成品入库闭环

- 前置：OperationExecution 已完成。
- 操作：提交合格数与不良数的 WorkReport，提交 Passed 的 QualityInspection，创建并确认 FinishedGoodsReceipt。
- 结果：`report_qty = qualified_qty + defect_qty`；成品库存只增加已检验合格且尚未入库的确认数量；工单可追溯全部事实。
- 失败：累计报工超上限返回 `MES_WO_003`；成品入库超出可入库数量返回 `MES_FG_001`。
- 幂等：重复确认成品入库不重复增加库存。

### 场景 5：质检失败阻止直接入库

- 前置：WorkReport 已存在。
- 操作：提交 Failed 的 QualityInspection，再尝试对对应数量确认 FinishedGoodsReceipt。
- 结果：保存失败质检事实，成品入库被拒绝并返回 `MES_QC_001`。
- 边界：系统不创建返工单，也不进入返工状态机。

### 场景 6：设备关联为可选项

- 前置：WorkOrder 与 DispatchOrder 合法。
- 操作：分别创建有关联 `device_id` 和未关联设备的 OperationExecution。
- 结果：两者均可按人工工序规则执行；有关联设备的记录可用于后续告警上下文追溯，但 MES 不复制 IoT 遥测或告警。
- 失败：设备引用与派工关系不一致时返回 `MES_EXE_002`。

## 自动化测试

- WorkOrder 人工来源关联成功、无来源创建成功、跨租户来源关联失败。
- 未下达 WorkOrder 不能下达派工或开始 OperationExecution。
- OperationExecution 开始、暂停、恢复、完成合法路径通过；每个非法重复操作返回 `MES_EXE_001`。
- DispatchOrder 与 WorkOrder、Operation 不一致时返回 `MES_DIS_001`。
- MaterialIssue 库存不足不产生部分库存事实；领料与退料重复确认不重复变化库存。
- WorkReport 的合格数加不良数正确，累计报工超上限返回 `MES_WO_003`。
- QualityInspection 失败后对应数量入库返回 `MES_QC_001`。
- FinishedGoodsReceipt 超出可入库数量返回 `MES_FG_001`，重复确认只增加一次库存。
- 跨租户查询返回空数据，跨租户写关联返回 `MES_TENANT_001`。

## 一期范围否定验收

- API、页面和自动化测试中不出现 WIP 库存或线边仓余额操作。
- 不存在自动 MRP、自动工单生成、产能日历、APS 或自动排产接口。
- 不存在返工单、返工执行或重复质检流程接口。
