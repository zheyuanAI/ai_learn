# 二维地图与综合看板业务规则

> 状态：一期目标设计已确认  
> 确认日期：2026-08-27

## 1. 页面与模块边界

- 二维地图和综合看板使用两个独立页面，共用同一套查询口径和权限上下文。
- 地图与看板只查询、汇总和跳转，不确认告警、不调整库存、不修改订单或工单。
- 除地图底图和点位位置配置外，本模块不保存第二套业务事实。
- 三维厂区、Cesium（三维地理场景引擎）和三维数字孪生进入后续阶段。

## 2. 二维地图

- 一个租户可以创建多张地图，例如厂区图、车间图和仓库图。
- 地图使用上传的二维图片作为底图。
- 点位使用相对百分比坐标，确保页面缩放后位置不偏移。
- 一期点位类型为仓库、生产区域和设备；点位只保存显示位置和源业务对象引用。
- 源业务对象不存在或已失效时，点位标记配置异常，由授权人员修复，不静默改指其他对象。

## 3. 配置权限

- 租户管理员维护地图、底图和通用点位。
- 具有地图配置权限的 IoT 人员可以维护设备点位。
- 普通查询用户只能查看权限范围内的地图和点位，不能拖动或保存位置。
- 点位保存必须校验同一租户并支持幂等（重复提交只保存一次结果）。

## 4. 点位状态与交互

点位状态为正常、预警、告警、离线，同时存在时按以下优先级显示：

```text
告警 > 离线 > 预警 > 正常
```

- 点击点位显示名称、对象类型、当前摘要、来源更新时间和允许跳转的业务详情入口。
- 跳转入口必须再次经过目标业务页面权限校验。
- 点位状态只用于展示，不驱动源业务状态变化。

## 5. 综合看板

看板固定提供七组摘要，每组展示 3～5 个核心指标，并允许进入明细页面：

| 摘要 | 一期核心内容 |
| --- | --- |
| 库存 | 实物量、预留量、可用量、库存异常 |
| 采购销售履约 | 采购待收货/待上架、销售待预留/待拣货/待发货 |
| 生产 | 待审核、已下达、生产中、正常完成、人工完成 |
| 质量 | 待检验、检验合格、不合格、待处理 |
| 设备 | 设备总数、在线、运行、离线 |
| 告警 | 活动告警、未确认、已恢复和等级分布 |
| 追溯 | 业务链完整数量、缺失关联数量和异常入口 |

一期不提供任意拖拽组件、任意公式或用户自定义统计口径。

## 6. 时间与刷新

- 时间范围支持今日、近 7 天、近 30 天，默认今日。
- 日期边界按租户时区计算，响应必须返回实际生效的起止时间。
- 页面默认每 30 秒自动刷新，并提供手动刷新入口。
- 页面显示本次投影生成时间和源事实最后更新时间，两者不得混用。

## 7. 来源故障与陈旧数据

- 某个源业务模块不可用时，对应区域显示“数据暂不可用”，其他区域继续展示。
- 可以保留上一次成功结果，但必须显著标记“已过期”及其生成时间，不能冒充实时数据。
- 不得用 0、空白或伪造值替代查询失败。

## 8. 权限与一致性

- 用户无权查看的点位、指标和明细入口直接隐藏，不用 0 或模糊值代替。
- 聚合统计只能包含当前用户有权查看的数据。
- 地图与看板对同一事实必须使用对应领域应用服务提供的相同口径，不在前端重新计算另一套指标。
- 跨租户筛选统一拒绝，不泄露目标实体是否存在。
