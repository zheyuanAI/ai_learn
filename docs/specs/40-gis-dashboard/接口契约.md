# 二维 GIS 与综合看板 API 契约

> 本文定义一期目标接口，当前 Controller 尚未实现这些业务路由。仓库中现有实现仅包含各服务的 `/internal/ping` 健康检查。

## 通用约束

- 所有接口要求 `Authorization`，并校验当前用户的租户上下文与查询权限
- 客户端不得通过参数指定或覆盖 `tenant_id`
- 除二维底图/点位展示配置外，本领域一期只提供查询；任何接口都不得修改源业务事实
- 查询通过对应领域应用服务获得数据，不允许跨模块直连表或建立第二套业务事实
- 所有响应返回 `request_id`、`generated_at`；时间范围查询同时返回实际生效的 `time_range`

## 二维地图目标接口

- `POST /api/site-maps`
- `GET /api/site-maps`
- `GET /api/site-map`
- `GET /api/site-map/points/{point_id}`
- `POST /api/site-map/points`

### `POST /api/site-maps`

- 必填：`map_code`、`map_name`、二维底图资源
- 语义：创建当前租户的二维地图配置；一个租户允许多张地图
- 坐标体系：点位统一使用 `x_percent`、`y_percent` 相对百分比

### `GET /api/site-map`

- 可选参数：`entity_type`、`status`
- 返回：二维底图、当前用户可查看的仓库/生产区域/设备点位、告警标记、`generated_at`

### `GET /api/site-map/points/{point_id}`

- 返回：点位展示信息、源业务实体引用、状态摘要、来源更新时间与允许跳转的业务页面

### `POST /api/site-map/points`

- 要求：`Authorization`、`Idempotency-Key` 和点位配置权限
- 必填：`site_map_id`、`entity_type`、`entity_id`、`x_percent`、`y_percent`
- 可选：`rotation`、`linked_page`
- 语义：只维护当前租户的二维展示配置，不修改被引用实体的业务状态

## 综合看板目标接口

- `GET /api/dashboard/inventory`
- `GET /api/dashboard/fulfillment`
- `GET /api/dashboard/manufacturing`
- `GET /api/dashboard/quality`
- `GET /api/dashboard/device`
- `GET /api/dashboard/alarms`
- `GET /api/dashboard/traceability`

### 看板通用查询参数

- 可选：`time_range`，支持 `today`、`7d`、`30d`，未提供时默认 `today`
- 可选：`warehouse_id`、`production_area_id`、`device_id`
- 筛选值必须属于当前租户且在当前用户权限范围内

### 看板通用返回字段

- `summary_type`
- `metrics`
- `time_range`：实际生效的起止时间
- `source_summary`：参与聚合的领域来源摘要
- `generated_at`
- `stale`：源服务不可用但返回上次成功结果时为 `true`
- `stale_since`：陈旧结果原生成时间，仅在 `stale = true` 时返回

## 业务错误码

- `GIS_AUTH_001`：当前用户无地图或看板查询权限
- `GIS_TENANT_001`：筛选实体不属于当前租户或发生跨租户访问
- `GIS_QUERY_001`：统计时间范围不支持
- `GIS_QUERY_002`：源领域查询暂时不可用
- `GIS_POINT_001`：点位不存在或当前用户不可见
