# 二维 GIS 与综合看板验收清单

## 核心验收

- 二维地图可展示当前租户内且当前用户有权查看的仓库、生产区域和设备点位
- 告警标记与 IoT 告警事实的标识、级别、状态和时间一致
- 综合看板可按统一时间范围展示库存、履约、制造、质量、设备、告警和追溯摘要
- 相同源事实经地图和看板查询时，业务标识、状态和统计口径一致
- 地图与看板不形成第二套业务事实，不修改源领域数据
- 有权限用户可保存当前租户的点位坐标；保存点位不会改变被引用实体的业务状态

## 页面验收

- 地图页至少展示二维地图主画布、点位详情、状态颜色、来源更新时间和业务跳转入口
- 首页看板至少展示库存、履约、制造、质量、设备、告警和追溯七类摘要
- 页面明确展示实际生效的统计时间范围和投影生成时间
- 一期页面和接口中不包含 Cesium 或三维模型能力

## 权限与错误码验收

- 无查询权限时返回 `GIS_AUTH_001`
- 跨租户筛选或引用实体时返回 `GIS_TENANT_001`，且响应不泄露目标实体是否存在
- 不支持的时间范围返回 `GIS_QUERY_001`
- 源领域查询不可用时返回 `GIS_QUERY_002`，不得用伪造值代替
- 点位不存在或无权查看时统一返回 `GIS_POINT_001`

## 自动化测试

- 地图和七类摘要查询均按租户与用户权限过滤
- 点位配置保存支持幂等，且拒绝跨租户实体引用
- 查询接口只有读取行为，不产生源领域写操作
- 告警数据在地图与看板之间一致
- `time_range`、`generated_at` 和来源摘要返回完整
- 所有目标错误码均有至少一个自动化用例
