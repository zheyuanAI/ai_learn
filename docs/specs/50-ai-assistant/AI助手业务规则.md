# AI 助手业务规则

> 状态：一期目标设计已确认  
> 确认日期：2026-08-27

## 1. 一期定位

AI 助手提供自然语言只读查询、解释、汇总和建议，不代替业务人员作决定，也不执行任何写操作。

各角色都可以在获得 AI 功能权限后使用，但只能查询该用户原本有权查看的租户和业务数据。AI 不是超级管理员。

## 2. 模型、Open WebUI 与 Provider

- 默认模型通过硅基流动 OpenAI 兼容接口调用，当前模型标识为 `deepseek-ai/DeepSeek-V4-Flash`，基础地址为 `https://api.siliconflow.cn/v1`。
- 目标架构由自托管 Open WebUI 管理硅基流动连接、WMS 模型预设、受控知识和多轮查询工具编排。
- 浏览器端不直接访问 Open WebUI 或硅基流动，由 Core 统一代理调用、恢复 WMS 用户上下文、执行工具权限校验和审计。
- 早期 DeepSeek 直连 Provider 只保留为诊断回退代码；默认运行路径为 Open WebUI，同一次请求只能启用一种 Agent 编排路径。
- Open WebUI、模型编号、基础地址和密钥全部来自部署环境配置，不写死在业务代码中；后续更换模型时通过配置或 Provider 适配器完成。

目标配置语义：

```text
WMS_AI_ENABLED=false
WMS_AI_PROVIDER=open-webui
WMS_OPENWEBUI_BASE_URL=http://127.0.0.1:3000
WMS_OPENWEBUI_API_KEY=<仅从安全环境读取>
WMS_OPENWEBUI_MODEL=wms-assistant
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=deepseek-ai/DeepSeek-V4-Flash
SILICONFLOW_API_KEY=<仅从安全环境读取>
```

实际部署模型编号必须以 Open WebUI 中已验证的硅基流动连接为准。Open WebUI、知识库或模型不可用时必须显式返回服务不可用；不得伪造成功响应或由客户端静默切换模型。

## 3. 流式问答协议

- 正常聊天使用 `POST /api/ai/chat/stream`，以 `text/event-stream` 返回流式事件；非流式 `POST /api/ai/chat` 用于兼容和自动化测试。
- Open WebUI 上游调用必须支持知识检索和原生多轮工具循环；具体事件映射以最小可行性验证结果为准，不把未验证协议写死进业务代码。
- 浏览器下游事件固定为 `meta`、`progress`、`tool_started`、`tool_finished`、`delta`、`done`、`error`。
- `delta` 只展示最终回答文本，不展示模型思维链；兼容期如保留 `actions` 事件，只能发送空集合。
- 用户中止或网络断开时，已完成的工具调用仍须审计，未完成的助手消息标记为中断，不得冒充完整回答。

## 4. 受控只读业务 API

AI 只能调用唯一 YAML 白名单登记的现有业务查询接口：

- 查询低库存和指定产品/仓库库存；
- 查询销售订单、采购订单和生产工单进度；
- 查询质量统计和设备告警；
- 查询黄金业务闭环上下游追溯；
- 查询当前用户有权查看业务对象的结构化操作审计；
- 基于上述结果生成按需文字日报。

AI 不得直连数据库，不得生成或执行 SQL（数据库查询语句），不得跨模块访问数据仓储层，也不得调用未登记业务接口。

- `deploy/openwebui/wms-ai-api-whitelist.yml` 是唯一维护的 AI API 能力上限；
- 白名单按业务模块分组以便阅读，不按角色复制；角色变化由现有 Spring Security 授权数据承接；
- 每项必须精确登记服务、operation id、HTTP method 和 path，禁止通配路径和模型提供任意 URL；
- Gateway 读取 YAML 并裁剪 Core/IoT 现有 OpenAPI，Open WebUI 配置脚本只消费该派生目录，不直接导入完整业务 OpenAPI；
- 工具实际可用范围是 YAML 白名单、当前用户实时权限和本次请求限制的交集；
- 业务接口返回内容由模型按问题提取和关联，不为 AI 重复编写字段裁剪 DTO 或相同查询逻辑；
- Open WebUI 不注册通用 HTTP、Shell、文件系统、代码执行、联网搜索或写工具。

## 5. 工具选择与页面上下文

- AI 根据用户问题自动选择必要工具；用户可以进一步限制本次允许使用的工具，但不能扩大后端权限。
- 从订单、工单或设备页面打开 AI 时，可以携带当前业务对象类型和编号。
- 页面只传递明确的业务标识，不把整个页面或无关数据发送给模型。
- 所有业务 API 参数由现有 Controller/ApplicationService 再次校验租户、用户权限、数据范围、时间范围和数量上限。
- 本阶段不生成页面导航动作；涉及多个角色时只用文字说明主责角色、协同角色和建议处理顺序。

## 6. 受控项目知识

- 仅同步 `docs/ai-knowledge/knowledge-manifest.yaml` 明确列出的知识文件；
- 正式领域规格和实际代码仍是事实源，AI 知识目录不能成为第二套业务规则；
- 不同步历史计划、废止规则、密钥、日志、数据库备份、构建产物和整个代码仓库；
- 知识回答必须标明规则来源；实时状态、数量和操作历史仍必须调用 WMS 工具；
- 当前阶段使用 Open WebUI 自有知识能力，不允许其直连 WMS PostgreSQL，不新增 WMS 自建 MinIO 或 pgvector。

## 7. 回答依据

每次回答必须展示或携带：

- 数据来源模块和业务对象摘要；
- 实际统计时间范围；
- 调用的工具摘要；
- 请求编号；
- 实际使用的模型编号。

没有权限、没有数据、查询超时或来源失败时必须明确说明，禁止根据模型记忆或历史对话编造业务结果。

多个查询部分失败时，返回已经取得的授权事实，并明确标出缺失部分，不让单个来源故障掩盖全部有效结果。

## 8. 写操作边界

- AI 可以解释异常、说明涉及角色和建议处理顺序。
- AI 不得创建、修改、提交、审核、确认、完成或删除订单、库存、工单、质检、设备和告警数据；第一批 YAML 只登记查询接口。
- 即使用户在对话中表示同意，AI 一期也不能执行写操作。
- 当前阶段不向 Open WebUI/硅基流动模型注册任何写接口；AI 只能使用 YAML 登记的只读查询接口。
- 后续若开放写能力，除调整 YAML 外仍必须另行设计“操作草案、后端预校验、用户明确确认、现有命令接口执行、幂等与审计”机制；不能仅把写接口加入清单就视为可安全执行。

## 9. 日报

- 日报按用户请求即时生成，只组合本次受控查询结果。
- 日报不是正式业务事实，不自动写入报表库，不自动定时发送。
- 缺少数据时在对应章节明确说明，不由 AI 补齐数值。

## 10. 会话、身份委托与审计

- 用户可以查看自己的历史会话。
- 具有 AI 审计权限的人员可以查看当前租户范围内的工具调用记录。
- 成功、失败、超时和拒绝的每次工具调用都必须记录审计，并与回答使用同一请求编号。
- 审计至少记录用户、会话、工具、输入/输出摘要、来源、时间范围、实际模型、耗时、状态和错误原因。
- 审计和会话不得保存登录密码、设备凭证、中转站密钥或无关敏感数据。
- 兼容字段中的导航动作摘要固定为空；后续真实业务操作继续使用各领域既有审计。
- 业务操作审计与 AI 工具调用审计是两类记录：前者解释用户或系统对业务对象执行的动作，后者解释 AI 为回答问题调用了哪些只读工具。
- Auth、Core、IoT 分别保存本服务操作审计；AI 通过受控工具聚合，不允许跨服务直连审计表。
- 普通页面点击和筛选不进入业务操作审计；创建、修改、提交、审核、确认、完成、取消、库存变化、告警处理和权限调整必须记录。
- 系统只承诺识别账号、用户 ID 与会话；共享账号背后的实际自然人未在仓库中确认，AI 不得推断。
- Open WebUI API Key 只代表模型平台调用身份，不代表 WMS 用户；Open WebUI 调用业务 API 时必须通过 Gateway 服务签名和短期服务端上下文映射。
- Open WebUI chat/message 标识只用作关联键；Gateway 必须重新检查当前有效 `jti` 和 YAML 白名单并恢复可信身份，下游业务接口再使用既有 Spring Security 检查实时权限、租户和数据范围，不能单独信任这些 Header。

## 11. 外部模型平台安全与故障

- Open WebUI 与硅基流动属于独立数据处理边界，只向其发送回答所需的最小授权知识片段和业务摘要。
- 真实 Open WebUI/硅基流动密钥和服务签名只能保存在安全环境变量或秘密管理设施中，不进入源代码、Git、普通配置样例或日志。
- Open WebUI、Knowledge 或硅基流动不可用时，AI 页面明确显示服务不可用，不影响库存、订单、生产和设备等核心业务。
- 未配置密钥的本地环境可以展示显式标记的模拟模式，但模拟结果不得冒充真实业务查询。

## 12. 二期边界

- 通用文档上传平台、WMS 自建 RAG、MinIO 和 pgvector 进入二期；当前阶段只同步 `docs/ai-knowledge/` 清单内受控知识。
- AI 写操作、自动代理执行、自动定时报表和外部联网搜索不进入一期。
