# AI 助手 API 契约

> 本文定义一期目标接口，当前 Controller 尚未实现这些业务路由。仓库中现有实现仅包含各服务的 `/internal/ping` 健康检查。

## 通用约束

- 所有接口要求 `Authorization`，并使用服务端认证上下文校验租户、用户和数据权限
- 客户端请求不得包含可覆盖认证上下文的 `tenant_id` 或 `user_id`
- AI 只能通过应用服务的受控只读工具查询；不得直连表、生成或执行 SQL、写业务数据或触发状态迁移
- 所有响应必须附带 `request_id`
- 每次工具调用均写入审计，包括被拒绝、失败和超时的调用

## 会话与审计目标接口

- `POST /api/ai/chat`
- `GET /api/ai/tool-audit-logs`

### `POST /api/ai/chat`

- 必填：`message`
- 可选：`session_id`、`tool_whitelist`
- `tool_whitelist` 只能从当前用户获准工具中进一步缩小范围
- 返回：`request_id`、`answer`、`source_summary`、`time_range_summary`、`tool_call_summary`

### `GET /api/ai/tool-audit-logs`

- 可选参数：`session_id`、`tool_name`、`status`、`time_range`
- 返回字段至少包括：租户、用户、请求标识、工具、输入摘要、输出摘要、来源摘要、时间范围摘要、工具调用摘要、耗时、状态和错误信息
- 只能查询当前租户且在当前用户审计权限范围内的记录

## 只读业务工具目标接口

- `POST /api/ai/tools/queryLowStock`
- `POST /api/ai/tools/queryInventoryByProductAndWarehouse`
- `POST /api/ai/tools/querySalesOrderStatus`
- `POST /api/ai/tools/queryPurchaseOrderStatus`
- `POST /api/ai/tools/queryWorkOrderProgress`
- `POST /api/ai/tools/queryQualityStatistics`
- `POST /api/ai/tools/queryDeviceAlarm`
- `POST /api/ai/tools/queryTrace`
- `POST /api/ai/tools/generateDailyOperationReport`

这些 `POST` 仅用于提交结构化查询条件，不表示写业务数据。

### 工具接口通用请求体

- 可选：`filters`
- 可选：`time_range`
- 可选：`limit`
- 禁止：`tenant_id`、`user_id`、原始 SQL 或可执行脚本

### 工具接口通用返回字段

- `request_id`
- `data`
- `source_summary`
- `time_range_summary`
- `tool_call_summary`

### `queryTrace`

- 必填：`entity_type`、`entity_id`
- 可选：`time_range`、`direction`、`limit`
- 返回：当前用户有权查看的关键上下游关联、来源摘要和实际数据时间范围
- 不得因为追溯关系而绕过关联实体自身的租户和数据权限

## 业务错误码

- `AI_AUTH_001`：当前用户无 AI 或指定工具调用权限
- `AI_TENANT_001`：跨租户访问被拒绝
- `AI_INPUT_001`：查询条件、时间范围或数量限制非法
- `AI_TOOL_001`：受控工具调用失败
- `AI_TOOL_002`：工具不在服务端许可范围或未注册
- `AI_TOOL_003`：工具调用超时
- `AI_SOURCE_001`：没有可用于回答的授权事实来源
