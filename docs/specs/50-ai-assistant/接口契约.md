# AI 助手 API 契约

> 本文定义一期接口。当前已实现聊天、SSE、能力、会话历史、审计查询、10 个只读工具和 Open WebUI Agent 链路；真实可用性仍取决于本机 Open WebUI、硅基流动连接以及对应领域事实源是否启动。

## 通用约束

- 所有接口要求 `Authorization`，并使用服务端认证上下文校验租户、用户和数据权限
- 客户端请求不得包含可覆盖认证上下文的 `tenant_id` 或 `user_id`
- AI 只能通过应用服务的受控只读工具查询；不得直连表、生成或执行 SQL、写业务数据或触发状态迁移
- 所有响应必须附带 `request_id`
- 每次工具调用均写入审计，包括被拒绝、失败和超时的调用
- 目标架构通过服务端配置的 Open WebUI API 调用绑定硅基流动、Knowledge 和查询工具的模型预设；客户端不得传入或覆盖 Open WebUI/模型平台地址、API Key、模型编号和知识库标识
- 当前硅基流动基础模型为 `deepseek-ai/DeepSeek-V4-Flash`，WMS 调用的 Open WebUI 预设为 `wms-assistant`；后续切换模型只能修改服务端配置或 Provider 适配器，不得由客户端静默切换
- 早期直连 DeepSeek Provider 只作为诊断回退代码保留；默认且已验证的运行路径为 Open WebUI，同一次请求不能执行两套工具循环

## 会话与审计目标接口

- `POST /api/ai/chat`
- `POST /api/ai/chat/stream`
- `GET /api/ai/capabilities`
- `GET /api/ai/chat-sessions`
- `GET /api/ai/chat-sessions/{sessionId}/messages`
- `GET /api/ai/tool-audit-logs`

### `POST /api/ai/chat`

- 必填：`message`
- 可选：`session_id`、`tool_whitelist`、`page_context`
- `tool_whitelist` 只能从当前用户获准工具中进一步缩小范围
- `page_context` 只允许包含 `entity_type`、`entity_id`、`entry_page_code`
- 返回：`request_id`、`session_id`、`answer`、`source_summary`、`time_range_summary`、`tool_call_summary`、`model_id`、`status`
- 兼容期如仍保留 `navigation_actions` 字段，必须固定返回空集合

### `POST /api/ai/chat/stream`

- 请求体与非流式聊天接口一致，响应类型为 `text/event-stream`
- 事件固定为：`meta`、`progress`、`tool_started`、`tool_finished`、`delta`、`done`、`error`
- `meta` 必须最先返回 `request_id`、`session_id` 和 `model_id`
- `delta` 只包含最终回答增量文本，不向客户端输出模型思维链
- 兼容期接收到 `actions` 时只能为空集合；当前阶段前端不展示导航动作
- `done` 返回来源摘要、实际数据时间范围、工具摘要、模型编号、Token 用量和完成状态
- 流在 `done` 或 `error` 后结束；断流时已完成的工具调用仍必须审计

### `GET /api/ai/capabilities`

- 返回当前用户获准使用的 AI 工具和建议问题类别，不返回导航动作类别
- 能力根据可信权限上下文计算，客户端不能请求扩大能力集合

### 会话历史接口

- 只能查询当前登录用户在当前租户内的会话和消息
- 具有 `ai:audit:view` 不等同于可以读取其他用户完整聊天正文；审计接口只返回已脱敏工具摘要

### `GET /api/ai/tool-audit-logs`

- 可选参数：`session_id`、`tool_name`、`status`、`time_range`
- 返回字段至少包括：租户、用户、请求标识、工具、输入摘要、输出摘要、来源摘要、时间范围摘要、工具调用摘要、实际模型编号、耗时、状态和错误信息
- 只能查询当前租户且在当前用户审计权限范围内的记录

## 只读业务工具目标接口

- `GET /v3/api-docs/ai-tools`
- `POST /internal/ai/tools/queryLowStock`
- `POST /internal/ai/tools/queryInventoryByProductAndWarehouse`
- `POST /internal/ai/tools/querySalesOrderStatus`
- `POST /internal/ai/tools/queryPurchaseOrderStatus`
- `POST /internal/ai/tools/queryWorkOrderProgress`
- `POST /internal/ai/tools/queryQualityStatistics`
- `POST /internal/ai/tools/queryDeviceAlarm`
- `POST /internal/ai/tools/queryTrace`
- `POST /internal/ai/tools/queryOperationAudit`
- `POST /internal/ai/tools/generateDailyOperationReport`

这些 `POST` 仅用于提交结构化查询条件，不表示写业务数据。

`/v3/api-docs/ai-tools` 只发布 `/internal/ai/tools/**` 下代码固定的 AI 查询工具；运行时仍受部署配置启用名单进一步裁剪。禁止发布任意业务 Controller 或接受动态 URL。Open WebUI 调用工具时还必须通过服务间认证，并携带可映射到本次 WMS 请求的 chat/message 标识。标识本身不是认证凭据。

### 工具接口通用请求体

- 各工具使用独立严格 DTO，只接受对应 OpenAPI 明确列出的字段
- `time_range` 只允许 `today`、`7d`、`30d` 中对应工具声明的值；`limit` 最大为 100
- 禁止：`tenant_id`、`user_id`、原始 SQL 或可执行脚本

### 工具接口通用返回字段

- `request_id`
- `data`
- `source_summary`
- `time_range_summary`
- `tool_call_summary`

### `queryTrace`

- 必填：`entity_type`、`entity_id`
- 可选：`time_range`、`direction`、`limit`
- 返回：当前用户有权查看的关键上下游关联、来源摘要和实际数据时间范围
- 不得因为追溯关系而绕过关联实体自身的租户和数据权限

### `queryOperationAudit`

- 必填：`entity_type`、`entity_id`
- 可选：`occurred_from`、`occurred_to`、`limit`，其中 `limit` 最大为 100
- 返回：当前租户、当前用户有权查看对象的脱敏操作时间线、来源摘要和实际时间范围
- 必须先验证目标实体对应的领域查看权限；不能仅凭 `ai:chat:query` 查询任意对象操作历史
- 不返回请求原文、Authorization、密码、设备凭证、原始幂等键或未脱敏业务载荷
- `actor_account` 代表系统账号；共享账号场景不得将其解释为已确认的自然人身份

## 业务错误码

- `AI_AUTH_001`：当前用户无 AI 或指定工具调用权限
- `AI_TENANT_001`：跨租户访问被拒绝
- `AI_INPUT_001`：查询条件、时间范围或数量限制非法
- `AI_TOOL_001`：受控工具调用失败
- `AI_TOOL_002`：工具不在服务端许可范围或未注册
- `AI_TOOL_003`：工具调用超时
- `AI_SOURCE_001`：没有可用于回答的授权事实来源
- `AI_PROVIDER_001`：Open WebUI 或硅基流动服务不可用、鉴权失败、额度不足或目标模型不可用

## 二期接口边界

- 通用知识库上传、WMS 自建文档解析、MinIO 存储和 pgvector 索引接口放入二期；当前阶段只通过 Open WebUI 同步 `docs/ai-knowledge/` 清单内知识
- AI 写操作、外部联网搜索和自动定时报表不进入一期
