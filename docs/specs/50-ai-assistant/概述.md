# AI 助手概览

## 一期目标

提供受认证、租户和用户权限约束的自然语言只读查询入口。AI 只能调用应用服务暴露的受控只读工具查询库存、订单、工单、质量、设备告警和跨域追溯事实，并对每次回答和工具调用保留可审计信息。

## 一期关键场景

- 查询低库存、指定产品与仓库库存
- 查询销售订单、采购订单和生产工单进度
- 查询质量统计与设备告警
- 通过 `queryTrace` 查询黄金业务闭环的关键上下游关系
- 基于受控查询结果生成简单日报或告警解释
- 在回答与审计中展示来源、数据时间范围和工具调用摘要

## 安全边界

- AI 不是超级管理员，必须沿用当前认证用户的租户和数据权限
- AI 只能调用应用服务提供的工具白名单，不得直连数据库表、生成或执行 SQL
- AI 不得创建、修改或删除业务数据，不得触发业务状态迁移
- 工具参数必须再次校验租户、权限、范围和数量限制；模型输出不能替代后端授权
- 当前仓库仅有各服务 `/internal/ping` 健康检查；本领域 Controller 尚未实现

## 二期候选

- 知识库、文档上传与解析切分
- MinIO 文件存储、pgvector 向量检索与 RAG 问答
