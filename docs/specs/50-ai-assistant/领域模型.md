# AI 助手领域模型

## 核心实体

### `ChatSession`

- 字段：`id`、`tenant_id`、`session_no`、`user_id`、`question_count`、`last_message_at`、`created_at`、`updated_at`

### `ChatMessage`

- 字段：`id`、`tenant_id`、`session_id`、`role`、`content`、`source_summary`、`time_range_summary`、`tool_call_summary`、`model_id`、`created_at`、`updated_at`
- 规则：助手回答必须同时保存来源摘要、数据时间范围摘要和工具调用摘要

### `ToolAuditLog`

- 字段：`id`、`tenant_id`、`user_id`、`session_id`、`request_id`、`tool_name`、`input_summary`、`output_summary`、`source_summary`、`time_range_summary`、`tool_call_summary`、`model_id`、`duration_ms`、`status`、`error_code`、`error_reason`、`created_at`、`updated_at`
- 规则：无论成功、失败、超时或拒绝，工具调用均须记录审计；摘要不得记录凭证或无关敏感数据

## 一期受控只读工具

- `queryLowStock`
- `queryInventoryByProductAndWarehouse`
- `querySalesOrderStatus`
- `queryPurchaseOrderStatus`
- `queryWorkOrderProgress`
- `queryQualityStatistics`
- `queryDeviceAlarm`
- `queryTrace`
- `generateDailyOperationReport`

`generateDailyOperationReport` 只组合上述受控查询结果生成文本，不写入业务领域，也不替代正式报表事实。

## 关键规则

- 认证上下文由服务端提供；模型和客户端均不得声明或覆盖 `tenant_id`、`user_id` 和权限范围
- 工具通过对应领域应用服务查询，不得直连表、拼接或执行 SQL、跨模块访问 Repository
- 工具白名单只能缩小当前用户可调用范围，不能扩大后端授予的权限
- 查询结果必须按租户、数据权限、时间范围和数量上限过滤
- 回答只能基于本次已授权工具返回的事实；无法取得依据时必须明确说明无可用事实依据
- 回答和审计必须关联相同的 `request_id`，并保留来源、实际数据时间范围和工具调用摘要
- 模型家族使用 Grok，通过 PokeAPI 的 OpenAI 兼容 Responses API 调用；默认优先 `grok-4.6`，实际模型编号由部署配置决定并写入审计
- PokeAPI 基础地址、模型编号和密钥均来自服务端安全配置；客户端不得覆盖，密钥不得写入会话或审计
- Grok 自带联网搜索和 X 搜索一期不启用，只允许调用 WMS 注册的受控只读工具
- 工具调用状态：`Success`、`Failed`、`Timeout`、`Denied`

## 二期模型边界

- `KnowledgeDocument`、`KnowledgeChunk`、文档索引状态及 RAG 检索模型放入二期
- MinIO 与 pgvector 不作为一期 AI 助手依赖
