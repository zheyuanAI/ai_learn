# AI 助手验收清单

## 核心验收

- 已认证且获授权的用户可通过 YAML 白名单内的现有业务查询接口查询库存、订单、工单、质量、告警和追溯事实
- `queryTrace` 只能返回当前租户且当前用户有权查看的关键上下游关联
- AI 可基于受控查询结果生成简单日报和告警解释，但不写入业务领域
- 每条回答均展示来源摘要、实际数据时间范围和工具调用摘要
- 每次工具调用无论成功、失败、超时或拒绝均有审计记录，并与回答使用同一 `request_id`
- 回答和审计记录实际使用的 Open WebUI 模型预设和 DeepSeek 模型编号；客户端不能覆盖地址、密钥、模型或知识库配置
- 流式聊天按 `meta -> progress/tool/delta -> done` 语义返回，最终正文不混入模型思维链
- 当前阶段不展示页面导航按钮；涉及多个角色时以文字区分主责、协同角色和建议处理顺序
- AI 能检索 `docs/ai-knowledge/` 清单内知识，并区分知识规则来源与实时业务事实来源
- `queryOperationAudit` 只按可信租户和目标实体领域查看权限返回脱敏操作时间线，不返回原始会话标识或幂等键
- 销售订单创建、修改、提交、审核和人工完成的成功审计与业务事务一致提交；相同幂等命令成功重放不重复记录

## 安全验收

- 未认证或无权限用户不能调用 AI 及业务工具
- 客户端或模型不能覆盖服务端租户、用户和权限上下文
- AI 只能调用唯一 YAML 精确登记的现有业务查询接口；这些接口继续调用领域 ApplicationService 或 Facts 端口，不接受模型 SQL、不执行写 SQL、不跨模块访问 Repository
- 未向 Open WebUI/DeepSeek 注册联网搜索、Shell、文件系统、代码执行、通用 HTTP 或写工具，模型只能使用 WMS 受控只读查询工具
- Open WebUI 服务身份、chat/message 标识均不能单独取得业务数据；必须恢复原 WMS 用户、有效 `jti`、租户和实时权限
- `wms-ai-api-whitelist.yml` 是工具安全上限，禁止重复维护第二份 operation 清单；Gateway 和 Open WebUI 配置脚本只能从该文件生成目录
- 聊天、日报、告警解释和追溯查询均不得创建、修改或删除业务数据，也不得触发状态迁移
- `tool_whitelist` 只能缩小权限，不能扩大当前用户获准的工具集合
- 审计摘要不保存认证凭证或无关敏感数据
- 业务操作审计按 Auth、Core、IoT 服务分别拥有和保存，AI 不得跨服务直连审计表
- 共享账号场景只能说明账号、用户 ID 和会话引用，不得据此声称识别实际自然人

## 页面验收

- 聊天页展示问题、回答、来源摘要、时间范围摘要、工具调用摘要、实际模型编号和 `request_id`
- 聊天页逐步展示进度和回答增量，支持停止生成；断流时保留已有内容并明确标记中断
- 状态诊断需要人工处理时只展示文字建议，不产生动作编码、外部 URL 或页面跳转按钮
- 审计页展示租户、用户、请求标识、工具、输入/输出摘要、来源摘要、时间范围、工具调用摘要、耗时、状态和错误信息

## 权限与错误码验收

- 无 AI 或工具权限时返回 `AI_AUTH_001`
- 跨租户访问返回 `AI_TENANT_001`，且不泄露目标数据是否存在
- 非法查询条件返回 `AI_INPUT_001`
- 应用服务查询失败返回 `AI_TOOL_001`
- 未注册或未获许可工具返回 `AI_TOOL_002`
- 工具调用超时返回 `AI_TOOL_003`
- 无授权事实可支撑回答时返回 `AI_SOURCE_001` 或生成明确的无依据回答，不得编造结果
- DeepSeek 或目标模型不可用时返回 `AI_PROVIDER_001`，且不影响其他 WMS 业务

## 自动化测试

- 认证、租户和工具权限组合测试
- `queryTrace` 关联实体逐项权限过滤测试
- 所有目标错误码至少有一个自动化用例
- 成功、失败、超时和拒绝调用均生成完整审计
- 回答与审计均含来源、时间范围和工具摘要，并通过 `request_id` 关联
- 工具调用前后业务事实数量和状态不变
- 对原始 SQL、脚本及客户端租户覆盖参数的请求予以拒绝
- 对客户端传入的模型编号、基础地址或密钥覆盖参数予以拒绝
- 对 SSE 分帧、跨网络 chunk JSON、断流、停止生成和终止事件执行自动化测试
- 对兼容期空导航响应和前端不展示导航入口执行自动化测试
- 对 Open WebUI 服务认证、短期上下文、过期/伪造 chat/message 标识、失效 `jti` 和请求重放执行自动化测试
- 对 YAML 精确 method + path、服务签名、短期上下文、当前用户 Spring Security 权限和本次请求限制执行自动化测试
- 对业务操作审计的租户隔离、领域权限、幂等去重、会话脱敏和查询上限执行自动化测试
