# AI 助手验收清单

## 核心验收

- 已认证且获授权的用户可通过受控只读工具查询库存、订单、工单、质量、告警和追溯事实
- `queryTrace` 只能返回当前租户且当前用户有权查看的关键上下游关联
- AI 可基于受控查询结果生成简单日报和告警解释，但不写入业务领域
- 每条回答均展示来源摘要、实际数据时间范围和工具调用摘要
- 每次工具调用无论成功、失败、超时或拒绝均有审计记录，并与回答使用同一 `request_id`

## 安全验收

- 未认证或无权限用户不能调用 AI 及业务工具
- 客户端或模型不能覆盖服务端租户、用户和权限上下文
- 工具只能通过领域应用服务查询，不直连表、不生成或执行 SQL、不跨模块访问 Repository
- 聊天、日报、告警解释和追溯查询均不得创建、修改或删除业务数据，也不得触发状态迁移
- `tool_whitelist` 只能缩小权限，不能扩大当前用户获准的工具集合
- 审计摘要不保存认证凭证或无关敏感数据

## 页面验收

- 聊天页展示问题、回答、来源摘要、时间范围摘要、工具调用摘要和 `request_id`
- 审计页展示租户、用户、请求标识、工具、输入/输出摘要、来源摘要、时间范围、工具调用摘要、耗时、状态和错误信息

## 权限与错误码验收

- 无 AI 或工具权限时返回 `AI_AUTH_001`
- 跨租户访问返回 `AI_TENANT_001`，且不泄露目标数据是否存在
- 非法查询条件返回 `AI_INPUT_001`
- 应用服务查询失败返回 `AI_TOOL_001`
- 未注册或未获许可工具返回 `AI_TOOL_002`
- 工具调用超时返回 `AI_TOOL_003`
- 无授权事实可支撑回答时返回 `AI_SOURCE_001` 或生成明确的无依据回答，不得编造结果

## 自动化测试

- 认证、租户和工具权限组合测试
- `queryTrace` 关联实体逐项权限过滤测试
- 所有目标错误码至少有一个自动化用例
- 成功、失败、超时和拒绝调用均生成完整审计
- 回答与审计均含来源、时间范围和工具摘要，并通过 `request_id` 关联
- 工具调用前后业务事实数量和状态不变
- 对原始 SQL、脚本及客户端租户覆盖参数的请求予以拒绝
