## 可复核命令

```powershell
$repo = 'D:\AI\ai_learn_wms_ai\ai_learn_developProject'
@(Get-ChildItem -LiteralPath (Join-Path $repo 'docs/specs') -Recurse -File).Count
@(Get-ChildItem -LiteralPath (Join-Path $repo 'docs/openspec') -Recurse -File).Count
Test-Path (Join-Path $repo 'specs')

Push-Location (Join-Path $repo 'docs')

```

反引号路径检查必须同时覆盖普通 Markdown 链接和代码样式路径；不能只以 `RELATIVE_LINKS_CHECKED=0` 推导无断链。Git 未跟踪文件不由普通 `git diff --check` 覆盖，故本清单与文件计数、目录存在性和 CLI 输出一起作为迁移审计证据。
