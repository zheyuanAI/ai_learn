# 业务架构交互 HTML Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本仓库 `AGENTS.md` 禁止直接 Git Commit，因此所有任务只验证、不提交。

**Goal:** 建立独立、可扩展的业务架构浏览空间，提供预览页、总体关系总览和七个模块交互页，并在业务架构与原型空间之间提供小型主入口直达链接。

**Architecture:** `docs/业务架构/` 使用独立 HTML、`biz-*` 样式和数据驱动 JavaScript；`index.html` 负责预览与导航，`总览.html` 负责跨模块拓扑、黄金闭环、事实流和边界，各模块页复用同一渲染器。原型空间只通过共享 `app.js` 注入一个指向业务架构主入口的普通链接，不建立模块映射。

**Tech Stack:** 语义化 HTML5、原生 CSS、原生 JavaScript、静态 HTTP 服务、Playwright。

---

## 文件职责

- `docs/业务架构/index.html`：业务架构预览主入口。
- `docs/业务架构/总览.html`：跨模块总体关系与流程图。
- `docs/业务架构/*业务架构.html`：模块级独立入口。
- `docs/业务架构/assets/business-architecture-data.js`：七模块已确认架构内容。
- `docs/业务架构/assets/business-architecture.js`：预览、总览、模块图、节点详情和键盘交互。
- `docs/业务架构/assets/business-architecture.css`：独立 `biz-*` 视觉系统和响应式布局。
- `docs/prototype/assets/app.js`：向任意原型页注入业务架构主入口直达链接。
- `docs/prototype/assets/styles.css`：原型空间小型跳转链接样式。
- `README.md`、`docs/prototype/README.md`：记录项目目录、两个空间入口与边界。

- [x] **Step 1: 在共享原型脚本中注入普通链接**

```js
function renderBusinessArchitectureJump() {
  const inPagesDirectory = window.location.pathname.includes("/pages/");
  const href = inPagesDirectory ? "../../业务架构/index.html" : "../业务架构/index.html";
  document.body.insertAdjacentHTML(
    "afterbegin",
    `<a class="prototype-space-jump" href="${href}">业务架构 ↗</a>`
  );
}
```

函数添加完整中文注释；初始化时调用一次。这里仅计算主入口相对路径，不建立模块映射。
