# 销售直接拣货与采购先隔离后质检 Implementation Plan

> **For agentic workers:** 按当前会话内联执行；本仓库禁止 AI Git Commit。步骤使用复选框记录完成情况。

**Goal:** 将已确认的销售直接拣货主流程和采购接收后先隔离、再质检分流规则同步到正式规格、业务架构与静态原型。

**Architecture:** 销售页面只暴露“直接拣货”，库存模块在同一事务内自动建立等量预留并完成拣货移动，预留仍作为底层库存事实保留。采购由仓库先完成外观验收，拒收数量不入库；实际接收数量全部进入质量隔离位，生产质检人员检验后，合格货物放行到收货暂存位，不合格货物继续隔离并等待退回或报废处置。

**Tech Stack:** Markdown 业务规格、原生 JavaScript 数据驱动原型、静态 HTML、Node.js 语法检查与浏览器验证。
