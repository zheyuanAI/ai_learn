# Frontend

## 目标
- 使用 Vue 3 + TypeScript + Vite 承接真实业务页面开发
- 当前只搭壳，不写具体业务逻辑
- 页面结构与导航用于表达一期目标范围，不代表业务功能已经实现

## 本地开发环境基线
- 本前端工程使用 Node 20。
- 后端在 IDEA 中使用 Java 21 与 Maven 3.9.1。
- 自研项目的 PostgreSQL 16 统一使用端口 5433；参考工程可保留 Node 22 与 PostgreSQL 16（端口 5323）配置。
