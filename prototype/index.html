Spec Driven / Prototype First

制造协同与数字孪生平台原型总览

这套原型直接对应 `D:\AI\ai_learn\specs` 下的项目基线，用于先固定页面结构、核心字段、主要状态流转、权限点和接口占位，再进入后端与前端真实开发。

当前覆盖

  • 登录、首页、ERP/WMS、MES、IoT、GIS、AI 六大能力域均有原型入口
  • 每页标出权限点、关键接口、状态标签和主要动作
  • 采购、销售、工单、设备告警、地图、AI 六条演示主线可串联

冻结重点

  • 字段命名：表格列、筛选区、详情区字段即冻结候选
  • 状态机：页面状态标签直接回写到各模块状态机
  • 接口：关键接口卡片直接对应后续 API 合同

建议审查顺序

  • 先审采购入库、销售出库、工单执行三条主业务链
  • 再审设备告警、地图、三维联动
  • 最后审 AI 工具只读约束、知识库与审计

六条演示主线

01
采购入库闭环
采购单 -> 入库确认 -> 上架确认 -> 库存流水 -> 应付单
02
销售出库闭环
销售单 -> 冻结库存 -> 拣货确认 -> 出库确认 -> 应收单
03
MES 工单闭环
BOM -> 工艺路线 -> 工单 -> 派工 -> 报工 -> 质检 -> 成品入库
04
IoT 告警闭环
设备上报 -> 状态变化 -> 告警触发 -> 地图/看板联动
05
空间展示闭环
地图页 -> 三维页 -> 设备与仓库状态联动
06
AI 助手闭环
知识库问答 -> 只读工具调用 -> 日报/解释 -> 审计日志
