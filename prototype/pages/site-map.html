厂区地图页

地图页是设备、仓库、生产区域和告警的只读空间视图，沿用业务系统中的点位与状态事实，用于定位并跳转追溯，不建立第二套事实来源。

权限点

  • site-map:view
  • site-map:point:edit
  • alarm:view
  • warehouse:view
  • device:view

关键接口

  • GET /api/site-map
  • GET /api/site-map/points/{point_id}
  • POST /api/site-map/points
  • GET /api/dashboard/alarms

状态标签

  • 点位正常
  • 点位告警
  • 点位离线
  • 区域拥堵

主要动作

  • 查看来源事实
  • 追溯设备与工序执行
  • 追溯仓库与库存流水
  • 查看告警上下文

点位配置与只读追溯字段

联动追溯设备 / OperationExecution / 工单 / 仓库 / 库存流水 / 告警

一期地图只读展示业务事实；具备配置权限的用户可维护二维点位展示配置，但不得修改被引用实体的业务状态。

当前页面仅使用假数据表达一期只读地图目标，不代表对应接口或业务功能已经实现。
