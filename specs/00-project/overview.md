# 项目总览

## 项目目标
在 10 周内完成一个可演示的制造与仓储协同、设备数字孪生与 AI 助手平台，覆盖 ERP/WMS、MES、IoT、GIS/三维、AI 助手五大能力域。

## 范围
- ERP/WMS：采购、入库、上架、销售、冻结库存、拣货、出库、调拨、盘点、应收应付、收付款
- MES：BOM、工艺路线、工单、排程、派工、报工、质检、返工、成品入库
- IoT：MQTT、Modbus TCP、OPC UA 模拟接入，遥测、状态、告警、消息通知
- GIS/看板：二维厂区地图、设备/仓库点位、告警定位、简化三维、统计图表
- AI 助手：RAG、业务只读工具、告警解释、日报生成、调用审计

## 非目标
- 不追求生产级高可用部署
- 不追求复杂 APS 算法
- 不追求真实 PLC 厂商设备深度适配
- 不做会修改业务数据的 AI Agent

## 成功标准
- 六条演示主线全部可跑通
- 多租户隔离、权限控制、幂等和关键状态流转有自动化测试覆盖
- Docker Compose 可从零启动主要依赖与服务
- 每个子域都有 spec、原型、API 契约、验收清单
