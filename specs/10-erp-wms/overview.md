# ERP/WMS 概览

## 目标
实现采购入库、销售出库、调拨、盘点和稳定的库存底座。入库、出库后只生成应付/应收草稿，用于业务追溯，不在一期实现收付款、核销和账龄。

## 关键场景
- 采购单 -> 入库 -> 上架 -> 库存增加 -> 库存流水 -> 应付草稿
- 销售单 -> 冻结库存 -> 拣货 -> 出库 -> 库存扣减 -> 应收草稿
- 调拨单 -> 出库/入库 -> 库位间库存转移
- 盘点单 -> 差异确认 -> 盘盈盘亏入账

## 风险点
- 可用库存、冻结库存和实物库存的一致性
- 重复提交、重复确认导致的重复扣减
- 批次、序列号、保质期组合维度过多导致建模复杂

## 二期候选

- 收付款、核销、账龄及完整财务报表等完整财务能力
- 序列号、保质期及其与批次组合的复杂库存维度
