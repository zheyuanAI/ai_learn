# MES 验收清单

## 核心验收
- 能创建 BOM 和工艺路线并下达工单
- 工单可派工、报工、质检并生成成品入库
- 不良品可记录，质检失败后必须阻止成品入库
- 工单进度可在列表与详情中追踪

## 页面验收
- 工单列表至少展示：工单号、产品、计划数量、计划完工时间、当前工序、状态、已报工、不良数
- 工单详情必须展示：BOM、工艺路线、当前工序、派工列表、报工列表、质检结果
- 报工页必须显式区分：合格品数量、不良品数量、合计报工数量

## 场景验收

### 场景 1：工单执行闭环
- 前置：BOM、工艺路线已创建
- 操作：创建工单 -> 下达工单 -> 创建派工 -> 报工 -> 质检 -> 成品入库
- 结果：工单进度递增，质检通过后生成成品入库记录

### 场景 2：质检失败拦截
- 前置：工单已报工
- 操作：提交质检且结果失败
- 结果：记录不良数量和失败结果，未通过前不可直接成品入库

## 二期验收项

- 产能日历、自动排程、返工单和重复质检不进入一期验收

## 自动化测试
- 工单未下达不能报工
- 报工总量不能超过工单计划数量上限策略
- 质检失败后不能直接成品入库
- 已完成工单不能再次报工
- 成品入库数量不能超过工单可入库数量
- 跨租户查询工单返回空数据
